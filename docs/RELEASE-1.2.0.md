# LHPad 1.2.0 — 편집 기본기

Notepad++ 대체로 매일 쓰기 위해 먼저 필요한 편집 기본 기능을 추가한다.

## 추가

- **최근 파일**: `파일 → 최근 파일`. 직접 연 파일(열기·드래그 앤 드롭·명령줄·탐색기 메뉴), 저장한 파일, 닫은 파일을 최신 순 15개까지 기록한다. 대소문자만 다른 경로는 하나로 합친다. 세션 복원이 여는 스냅샷 파일은 기록하지 않는다. 없는 파일을 고르면 목록에서 제거할지 묻는다. `session.json`의 `RecentFiles`에 저장한다.
- **탭 관리**: 탭 드래그로 순서 변경, 다른 탭/오른쪽 탭/모든 탭 닫기, 파일 경로 복사, `Ctrl+Shift+T` 닫은 탭 다시 열기(저장된 파일만, 최대 20개). 일괄 닫기는 오른쪽부터 닫으며 저장 확인에서 취소하면 멈춘다.
- **설정 창**: `도구 → 설정…`. 탭 너비 1~16, Tab 키의 탭 문자/공백, 괄호 짝 강조, 자동 들여쓰기. `TabWidth`·`UseTabs`·`BraceMatch`로 세션에 저장한다. 기존 기본값(공백 4칸)은 그대로다.
- **주석 넣기 / 빼기** (`Ctrl+Q`): `data/langs.xml`의 `commentLine`/`commentStart`/`commentEnd`를 사용한다. 줄 주석은 들여쓰기 뒤에 `기호 + 공백`을 넣고, 비어 있지 않은 선택 줄이 모두 주석이면 뺀다. 블록 주석만 있는 언어(HTML 등)는 선택 영역 또는 현재 줄을 감싸거나 푼다. Markdown은 `<!-- -->`를 쓴다. 주석 기호가 없는 언어(일반 텍스트)는 안내한다.
- **대소문자 변환**: `Ctrl+Shift+U` 대문자, `Ctrl+U` 소문자(Scintilla 명령), 단어 첫 글자 대문자(작은따옴표는 단어 안으로 취급). 다중 선택을 지원한다.
- **괄호 짝**: 커서 앞·뒤의 `()[]{}`와 짝을 Scintilla 인디케이터 8/9로 표시한다. 언어를 바꿔도 스타일 초기화에 지워지지 않는다. `Ctrl+B`로 짝으로 이동한다.

주석 토글·단어 첫 글자 대문자·짝 괄호 이동은 매크로 단계(kind 8/9/10)로 기록·재생된다. 모든 편집은 한 번의 실행 취소로 되돌린다. 로그 모니터링 중인 탭에서는 실행하지 않는다.

## 기타

- 버전 번호를 `cpp/version.h` 한 곳에서 관리한다.
- 저장소를 git으로 관리한다 (`.gitattributes`로 줄바꿈 정규화).

## 검증

- `--self-test`에 주석 토글(C++ 줄 주석·HTML 블록 주석·주석 없는 언어), 대소문자 변환, 단어 첫 글자 대문자(한글 포함)와 실행 취소, 괄호 이동 왕복, 최근 파일 중복 제거·15개 제한·메뉴 항목, 탭 이동·오른쪽 탭 닫기·닫은 탭 다시 열기 검사를 추가했다.
- MinGW-w64(GCC 13) `-fsyntax-only -Wall -Wextra -Wshadow`로 변경 파일의 문법을 확인했다. 새 코드에서 경고는 없다.
- **MSVC 빌드와 `./build.ps1 -Test` 결과는 아직 기록되지 않았다.** Windows에서 실행한 뒤 결과를 여기에 추가한다.
