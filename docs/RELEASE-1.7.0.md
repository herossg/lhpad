# LHPad 1.7.0 — 줄 작업

## 추가

- `편집 → 줄 작업` 하위 메뉴. 모든 작업은 선택한 줄에, 선택이 없으면 문서 전체에 적용된다(이전에는 정렬에 선택이 필요했다). 선택이 다음 줄의 맨 앞에서 끝나면 그 줄은 포함하지 않는다. 문서가 줄바꿈으로 끝나면 마지막 빈 줄은 그대로 둔다.
  - 정렬: 오름차순·내림차순(바이트 순), 대소문자 무시(한글 포함, 같은 줄은 원래 순서 유지), 숫자(앞의 10진수 값 기준, 숫자로 시작하지 않는 줄은 원래 순서로 뒤에), 줄 순서 뒤집기
  - 제거: 중복 줄(처음 나온 줄 유지), 빈 줄(공백·탭만 있는 줄 포함)
  - 공백: 줄 끝 공백·탭 제거, 탭을 공백으로(탭 위치 기준, 한 글자 = 한 칸), 줄 앞 공백을 탭으로(들여쓰기 폭 유지, 남는 칸은 공백)
- 한 번에 실행 취소된다. 바뀐 것이 없으면 실행 취소 기록을 남기지 않는다. 선택했던 줄은 작업 후 다시 선택된다.
- 매크로에 새 단계(kind 11)로 기록된다. 1.7 이전에 녹화한 정렬 단계(kind 6)도 그대로 재생된다.

## 수정

- 저장한 매크로에 주석 넣기/빼기, 단어 첫 글자 대문자, 짝 괄호 이동(1.2~1.4에서 추가한 단계 8~10)이 들어 있으면 다시 실행할 때 매크로 파일을 읽지 못하던 문제를 고쳤다. 매크로 파일 검사가 단계 종류를 7까지만 허용하고 있었다.

## 검증

- `--self-test`에 줄 작업 12가지, 선택 영역 정렬과 재선택, 한 번 실행 취소, 변경 없을 때 실행 취소 기록 없음, 단계 8~11 매크로 저장 후 다시 읽기, 알 수 없는 줄 작업 거부 검사를 추가했다.
- 줄 작업 알고리즘을 Linux에서 따로 컴파일해 테스트 기대값 12개와 일치하는 것을 확인했다.
- MinGW-w64(GCC 13) `-fsyntax-only -Wall -Wextra -Wshadow`로 변경 파일 문법을 확인했다.
- **MSVC 빌드와 `./build.ps1 -Test` 결과는 아직 기록되지 않았다.**
