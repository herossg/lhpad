# LHPad 1.3.0 — 검색

## 추가

- **검색 결과 창**: 메인 창 아래쪽에 붙는 목록(가상 ListView). 파일/탭, 줄, 내용(앞 공백 제거, 최대 1,000바이트)을 표시한다. 더블클릭·Enter로 이동, `F4` / `Shift+F4`로 다음·이전 결과(끝에서 처음으로 순환). `검색 → 검색 결과 창`으로 보이거나 숨긴다. 높이는 창 높이의 1/3(120~260 논리 픽셀).
- **모두 찾기**: 찾기 창의 `모두 찾기`·`검색 → 모두 찾기`. 현재 텍스트 탭, `모든 텍스트 탭`을 켜면 열린 텍스트 탭 전체를 검색한다. 찾기 창과 같은 옵션(대소문자, 단어, Boost 정규식)과 빈 일치 처리를 쓴다. 최대 100,000개. 검색 중 문서가 바뀌면 중단한다. 탭을 닫은 뒤에도 저장된 파일이면 결과에서 다시 연다.
- **찾은 항목 모두 표시 / 표시 지우기**: 인디케이터 10(노란 둥근 상자)으로 현재 탭의 일치 항목을 표시한다. 문서 내용·실행 취소 기록은 바뀌지 않는다.
- **파일에서 찾기** (`Ctrl+Shift+F`, 찾기 창 `파일에서 찾기…`): 폴더, 파일 형식(`;`·`,`·공백으로 구분, `PathMatchSpecW`), 하위 폴더 포함, 대소문자·단어·정규식. 파일마다 인코딩을 감지해 UTF-8로 읽고 숨긴 Scintilla 버퍼에서 찾기 창과 같은 검색 엔진으로 찾는다. 바이너리, 256 MiB 초과, 읽기·디코딩 실패 파일은 건너뛰고 개수를 결과 제목에 표시한다. `.git`·`.svn`·`.hg` 폴더는 들어가지 않는다. 진행 상황은 상태 표시줄에 나오며 Esc·찾기 창 `중지`로 멈춘다. 마지막 폴더·형식·하위 폴더 옵션은 `FindFolder`·`FindFilter`·`FindSubfolders`로 세션에 저장한다.

파일에서 찾기는 디스크 내용을 검색하므로, 열린 탭의 저장하지 않은 변경은 반영되지 않는다. 파일에서 바꾸기는 이번 버전에 포함하지 않았다.

## 검증

- `--self-test`에 모두 찾기(줄·열·내용, 결과 창 행 수), 결과 이동과 순환, 모두 표시·지우기, 검색이 문서를 바꾸지 않음, 파일에서 찾기(형식 필터, 하위 폴더, 바이너리·.git 건너뛰기, 상대 경로·열, 한 폴더만), 결과에서 파일 열기, 결과 창 숨기기 검사를 추가했다.
- MinGW-w64(GCC 13) `-fsyntax-only -Wall -Wextra -Wshadow`로 변경 파일 문법을 확인했다.
- **MSVC 빌드와 `./build.ps1 -Test` 결과는 아직 기록되지 않았다.**
