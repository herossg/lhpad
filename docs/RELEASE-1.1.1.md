# LHPad 1.1.1 — 탐색기 메뉴 표시 경량화

2026-11-01. Windows 11 첫 우클릭 메뉴의 표시 경로를 경량화했습니다.

- GetState는 두 호출 모드 모두 선택 개수만 확인하고 즉시 S_OK를 반환합니다. 비어 있거나 100,000개를 초과하면 숨깁니다.
- 메뉴 구성 중 GetItemAt, 파일 속성, 파일 경로, 속성 저장소를 조회하지 않으며 E_PENDING으로 추가 조회를 예약하지 않습니다.
- 패키지의 파일 형식 `*` 등록을 유지합니다. 폴더 및 비파일 항목의 검증과 전체 경로 수집은 Invoke에서 수행하며, 검증에 실패하면 편집기를 실행하지 않습니다.
- 아이콘은 EXE 대신 이미 적재된 LHPadShell.dll의 리소스 2를 참조합니다.
- 파일 전달과 인수 이스케이프, 실행 중인 편집기로의 전달 코드는 유지합니다.
- EXE·DLL 5개와 MSIX를 기존 LHZip 개발 인증서로 서명하며 EXE·DLL에는 RFC3161 타임스탬프를 포함합니다.

검증 범위는 셸 명령의 표시 및 파일 전달 회귀, 아이콘 추출, 수정 전후 COM 메서드 측정과 배포 파일 서명입니다. 편집기 전체 회귀 테스트는 실행하지 않았습니다. 직접 COM 메서드의 소요 시간은 탐색기 화면 전체의 표시 시간과 다릅니다. 인위적으로 느린 Shell 공급자 측정은 실제 네트워크나 OneDrive의 측정값이 아닙니다.

ZIP 전체를 풀고 Register-LHPad.cmd를 실행하면 새 위치와 패키지 버전으로 메뉴가 등록됩니다. 기존 프로필은 유지합니다.
