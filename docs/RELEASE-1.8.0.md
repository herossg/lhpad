# LHPad 1.8.0 — Hex·비교 보완

## Hex

- **이전 찾기**: 찾기 창의 `이전 찾기`·`Shift+F3`이 Hex 탭에서도 동작한다. 선택 시작 앞에서 마지막 일치를 찾고, 없으면 파일 끝에서 다시 찾는다(`BinaryBuffer::findBackward`, 1 MiB 단위로 뒤에서 앞으로 읽음).
- **모두 바꾸기**: Hex 탭에서 사용할 수 있다. 겹치지 않는 일치 위치를 모두 찾은 뒤 조각 테이블을 한 번에 다시 만들어(`BinaryBuffer::replaceAll`) 일치가 많아도 느려지지 않고, 한 번의 실행 취소로 되돌린다. 중지하면 아무것도 바꾸지 않는다.
- **길이가 다른 바꾸기**: 바꾸기와 모두 바꾸기 모두 바꿀 값이 찾을 값보다 짧거나 길어도 된다. 뒤쪽 바이트는 그만큼 당겨지거나 밀린다(이전에는 같은 길이만 허용).

## 비교

- 비교 창 위에 `공백 무시`(공백·탭 전체), `대소문자 무시`(영문) 체크박스를 추가했다. 바꾸면 같은 위치에 새 비교 창을 열고 이전 창을 닫는다. 줄을 맞출 때만 정규화한 값을 쓰고 화면에는 원래 텍스트를 보여 준다. 선택은 `CompareIgnoreSpace`·`CompareIgnoreCase`로 세션에 저장한다.
- **글자 단위 차이**: 양쪽에 모두 있는 변경 줄 쌍에서 달라진 글자만 진한 배경(왼쪽 빨강, 오른쪽 초록)으로 표시한다. 공통 앞뒤를 잘라 낸 뒤 가운데 부분을 글자(UTF-8 코드 포인트) 단위 LCS로 비교하므로 "a1b2"와 "a3b4"는 숫자만, 한글은 글자 단위로 표시된다. 한 줄 10,000바이트 이하, 2만 쌍까지 표시한다. 다크 모드에서는 어두운 색을 쓴다.

## 수정 (버전 유지)

- 이전 세션의 탭 가운데 파일이 디스크에서 사라진 것을 실행할 때마다 "복원 보류"로 다시 경고하던 문제를 고쳤다. 저장하지 않은 변경이 없는 탭이면 시작할 때 한 번 목록으로 알리고(20개까지 표시), 세션에 다시 쓰지 않아 다음 실행부터는 안내가 나오지 않는다. 저장하지 않은 변경이 있는 탭은 지금처럼 복구 사본으로 복원한다. 네트워크 드라이브가 잠시 끊긴 경우도 같은 방식으로 빠지므로, 필요하면 최근 파일 목록에서 다시 연다.
- `--self-test`에 실제 세션 파일로 프로그램을 두 번 시작해 확인하는 검사 3개(첫 시작에 한 번 보고하고 나머지는 열림, 다음 세션에서 빠짐, 두 번째 시작에는 안내 없음)를 추가했다.

## 검증

- `inlineDiff`·`compareKey`를 Linux에서 따로 컴파일해 7개 사례(숫자 하나, 한글, 여러 군데, 같은 줄, 뒤에 추가, 빈 줄, 한글과 영문)와 키 생성이 기대대로인 것을 확인했다.
- `--self-test`에 글자 단위 차이와 비교 키, 비교 창의 변경 표시·글자 표시, 공백·대소문자 무시, Hex 이전 찾기(순환 포함), 모두 바꾸기(짧은 값)와 한 번 실행 취소, 긴 값으로 바꾸기 검사를 추가했다.
- MinGW-w64(GCC 13) `-fsyntax-only -Wall -Wextra -Wshadow`로 변경 파일 문법을 확인했다.
- 2026-11-21 Windows 11에서 `./build.ps1 -Test` (MSVC) 빌드 성공. 네이티브 자체 테스트 261개 전체 통과(1.7.0 줄 작업·매크로 다시 읽기 검사와 1.8.0 Hex·비교 검사 포함). 실제 마우스 OLE 드롭 테스트도 이번에는 통과했다.
