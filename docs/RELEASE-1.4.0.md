# LHPad 1.4.0 — 탐색

## 추가

- **북마크**: Scintilla 마커 24(`SC_MARK_BOOKMARK`)와 여백 2(클릭 가능). `Ctrl+F2` 표시/해제, `F2`/`Shift+F2` 다음·이전(순환), 모두 지우기, 찾은 줄 모두 북마크(찾기 옵션 그대로), 북마크한 줄 복사(문서 줄바꿈으로 연결), 북마크한 줄 삭제(확인 후, 한 번에 실행 취소). 삭제 전에 해당 줄 마커를 지워 이웃 줄로 북마크가 옮겨 가지 않게 했다. 문서별 북마크 줄 번호를 `session.json`의 `Bookmarks`에 저장한다.
- **같은 문서 위아래 분할**: 두 번째 Scintilla 창이 같은 문서 포인터를 공유한다. 포커스를 받은 창을 `Document::editor`로 바꿔 기존 명령·찾기·매크로가 그대로 현재 화면에 적용된다. 표시 순서는 `topPane`으로 고정한다. 글꼴·설정·기호 표시·언어·녹화는 두 화면 모두에 적용한다. 미리보기 모드와 함께 쓰지 않는다. 분할 상태는 세션에 저장하지 않는다.
- **함수 목록**: 오른쪽 가상 ListView. 언어 그룹별 줄 단위 규칙(`buildOutline`)으로 함수·클래스·네임스페이스·Markdown 제목·SQL 객체·INI 섹션 등을 찾는다. C 계열은 반환 타입 + 이름 + `(` 형태와 이어지는 `{`·한정자를 확인해 선언·호출·제어문을 제외한다. 400자 넘는 줄과 16 MiB 이후는 보지 않는다. 편집 후 400ms 대기 뒤 다시 계산한다. 표시 여부를 `OutlineVisible`로 저장한다.

## 툴바 아이콘

툴바 아이콘 25개를 하나의 규칙(16px 격자, 1px 회청색 윤곽선, 기능별 파스텔 색, 배경 상자 없음)으로 다시 그렸다. 배율별 PNG(16~48px)를 미리 만들어 화면 배율에 맞는 크기를 쓰므로 흐리지 않다. 모두 저장을 저장과 구분했고, 파일에서 찾기·북마크·같은 문서 분할·함수 목록 버튼을 추가했다. 원본 SVG와 생성 스크립트는 `tools/toolbar-icons/`에 있다. [미리보기](toolbar-icons-1.4-preview.png)

## 검증

- `--self-test`에 북마크(표시, 순환 이동, 복사, 삭제·실행 취소, 찾은 줄, 지우기), 분할 보기(같은 문서, 양쪽 편집, 포커스 전환, 닫기), 함수 목록(C++·Python·Markdown·SQL·JavaScript 규칙, 미지원 언어, 패널 표시·이동·숨기기) 검사를 추가했다.
- 함수 목록 규칙을 Linux에서 따로 컴파일해 테스트 기대값 6건을 확인했다. LHPad의 `app.cpp`(1,500줄)에서 함수 23개를 정확한 줄 번호로 찾았고 약 7ms 걸렸다.
- MinGW-w64(GCC 13) `-fsyntax-only -Wall -Wextra -Wshadow`로 변경 파일 문법을 확인했다.
- 2026-11-19 Windows 11에서 `./build.ps1 -Test` (MSVC) 빌드 성공. 네이티브 자체 테스트 211개 전체 통과(신규 21개 포함), 탐색기 메뉴 회귀 테스트 통과, 서명 5개 Valid. 배포 폴더에 배율별 툴바 아이콘 150개 포함, 테스트 화면 캡처에서 새 툴바 표시 확인.
