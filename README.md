# LHPad



Notepad++를 모티브로 만든 Windows x64 텍스트·Hex 편집기입니다. 텍스트는 Notepad++와 같은 Scintilla / Lexilla 엔진을 사용하고, Hex는 HxD의 오프셋·Hex·문자 영역과 데이터 검사 구성을 참고했습니다.



## 실행



**1.4.0은 북마크·같은 문서 분할 보기·함수 목록을 더한 C++20 / Win32 네이티브 버전입니다.** `artifacts/native-1.4.0/LHPad.exe`를 실행하세요. ZIP은 `artifacts/LHPad-native-windows-x64.zip`입니다. ZIP 전체를 같은 폴더에 풀어 실행합니다. **.NET 10과 Visual C++ 재배포 패키지를 따로 설치하지 않아도 됩니다.** C++ 런타임은 정적으로 연결했습니다.



Scintilla.dll, Lexilla.dll, WebView2Loader.dll, data 폴더를 실행 파일 옆에 두세요. Markdown·HTML·SVG 미리보기에는 **Microsoft Edge WebView2 Runtime**이 필요합니다. 원문 편집과 Hex 편집에는 브라우저를 만들지 않습니다. Node.js는 사용하지 않습니다. 이전 버전 창을 닫고 새 버전을 실행하면 같은 `%LOCALAPPDATA%\LitePad` 프로필에서 탭·미저장 내용·인코딩·매크로를 복원합니다. 최초 전환 시 기존 JSON 파일을 프로필의 `legacy-csharp-backup` 폴더에도 보존합니다. 개발 소스와 현재 빌드 캐시는 유지하며, 이전 버전 배포본과 임시 검증 자료는 정리합니다.



파일을 **편집 영역·탭·Hex 영역에 드래그 앤 드롭**하거나 `Ctrl+O`로 여러 파일을 여세요. 한글·공백 경로와 다중 파일을 지원하며, 이미 열린 파일은 해당 탭으로 이동합니다. 실행 시 파일 경로 인수도 받을 수 있습니다. 이름을 지정하지 않은 문서는 UTF-8로 시작합니다.



`Register-LHPad.cmd`를 실행하면 **Windows 11의 첫 우클릭 메뉴에 ‘LHPad로 열기’**가 등록됩니다. 최초 설치에는 개발 인증서를 신뢰하기 위한 관리자 승인이 필요할 수 있습니다. LHZip과 동일한 인증서(`CN=LHZip Development`, 지문 `537D10B46D7742E859498D5642863AEC947973CB`)로 EXE·셸 DLL·Scintilla.dll·Lexilla.dll·WebView2Loader.dll과 MSIX를 서명했습니다. EXE·DLL에는 RFC3161 타임스탬프도 포함합니다. 공개 인증서 `LHPad.Development.cer`를 함께 제공하며 개인 키는 배포하지 않습니다. 이미 인증서를 신뢰하는 PC에서는 `도구 → 탐색기에 ‘LHPad로 열기’ 등록` 또는 `LHPad.exe --register-shell`도 사용할 수 있습니다. Windows 10에서는 기존 우클릭 메뉴를 사용합니다. 여러 파일을 선택하면 실행 중인 LHPad의 새 탭으로 전달합니다. 제거는 도구 메뉴 또는 `LHPad.exe --unregister-shell`입니다. 기존 LitePad 메뉴는 교체하며 파일 연결 기본값은 바꾸지 않습니다. 배포 폴더를 옮겼다면 새 위치에서 다시 등록하세요.



이름은 LHPad로 바뀌었지만 기존 세션·미저장 내용·설정을 보존하도록 프로필 경로 `%LOCALAPPDATA%\LitePad`는 유지합니다.



1.0.1에서는 커서 이동·자동 백업·주기 작업이 탭 제목과 아이콘을 반복해서 다시 그리지 않습니다. 파일명·비교 표시·저장 상태가 달라진 탭의 해당 항목만 갱신합니다.



1.0.2에서는 탭의 `×`를 그리는 영역과 클릭 영역을 일치시켰습니다. 마우스를 올리면 연한 빨강 배경과 손 모양 커서가 나타나고, 누르면 더 진해집니다. 버튼 안에서 눌렀다 놓으면 해당 탭을 닫으며, 누른 채 밖으로 이동해 놓으면 취소됩니다. `×` 오른쪽 여백은 문서를 닫지 않습니다.



1.0.3에서는 툴바 아이콘과 탭 아이콘을 16 논리 픽셀로 줄이고 상하 여백을 축소했습니다. 툴바는 26 논리 픽셀 높이로 표시합니다. 실행 취소·다시 실행은 투명 배경의 곡선 화살표로 표시하며, 매크로 녹화·중지·실행·반복 버튼 앞뒤에 세로 구분선을 표시합니다. 현재 커서가 속한 접기 구간의 연결선과 접기 버튼은 빨간색으로 강조하고 나머지 구간은 회색으로 표시합니다.



## 기능



`보기 → 텍스트 편집기 글꼴…`에서 Windows에 설치된 글꼴과 크기(6~72pt), 추가 줄 간격(0~24px)을 선택합니다. 두 줄짜리 미리보기에서 글꼴과 줄 간격을 함께 확인합니다. 0px는 글꼴 기본 간격이며, 추가 간격은 글자 위아래에 나눠 적용하고 화면 배율에 맞춰 조정합니다. 모든 텍스트 탭과 줄 비교 창에 즉시 적용되고, 새 탭·언어 변경·재실행 후에도 유지됩니다. 기본값은 Consolas 11pt, 추가 줄 간격 0px입니다. 구문 강조색과 문서 내용, 탭별 확대/축소는 유지합니다. Hex 영역은 열 정렬을 위해 기존 고정폭 글꼴을 사용합니다.



| 영역 | 사용법 |

|---|---|

| 텍스트·바이너리 자동 구분 | BOM, UTF-8 유효성, UTF-16 패턴, 제어 문자, 바이너리 시그니처로 판단합니다. 보기 메뉴에서 텍스트/Hex로 다시 열 수 있습니다. |

| 대용량 텍스트 | 64비트 Scintilla 문서에 청크 단위로 읽고 저장합니다. 200 MiB 초과 파일은 구문 강조를 끕니다. |

| 대용량 Hex | 원본 바이트는 디스크에 두고 바뀐 부분만 메모리에 저장하는 piece table을 사용합니다. |

| Hex 편집 | Hex/문자 영역 클릭 또는 Tab으로 영역 전환. 16진수/문자 입력, 마우스·Shift 선택, Insert로 삽입/덮어쓰기 전환, Delete로 삭제, 실행 취소·다시 실행을 지원합니다. |

| 데이터 검사 | 선택 위치의 정수·실수를 Little/Big endian으로 확인합니다. |

| 찾기·바꾸기 | Ctrl+F / Ctrl+H. 일반·정규식, 대소문자·단어 단위, 앞으로·뒤로 찾기, 모든 텍스트 탭 바꾸기. Hex는 바이트/UTF-8/UTF-16 LE/ASCII 검색과 같은 길이 바꾸기를 지원합니다. |

| 모두 찾기·결과 창 | 찾기 창의 `모두 찾기` 또는 `검색 → 모두 찾기`. 현재 탭(`모든 텍스트 탭`을 켜면 열린 텍스트 탭 전체)의 일치 항목을 아래 검색 결과 창에 파일·줄·내용으로 나열합니다. 더블클릭·Enter로 이동하고 `F4` / `Shift+F4`로 다음·이전 결과로 갑니다. 최대 100,000개까지 표시합니다. |
| 찾은 항목 모두 표시 | 찾기 창의 `모두 표시` 또는 `검색 → 찾은 항목 모두 표시`. 현재 텍스트 탭의 일치 항목을 노란 배경으로 표시하며 문서 내용은 바꾸지 않습니다. `검색 → 표시 지우기`로 없앱니다. |
| 파일에서 찾기 | `Ctrl+Shift+F`. 폴더, 파일 형식(`*.cpp;*.h`), 하위 폴더 포함, 대소문자·단어 단위·정규식을 지정합니다. 디스크에 저장된 내용을 파일별 인코딩을 감지해 검색하고 결과를 검색 결과 창에 표시합니다. 결과를 열면 해당 파일을 일치 위치에서 엽니다. 바이너리 파일, 256 MiB 초과 파일과 `.git`·`.svn`·`.hg` 폴더는 건너뜁니다. Esc 또는 찾기 창의 `중지`로 멈춥니다. 마지막 폴더·형식은 세션에 저장됩니다. |
| 북마크 | `Ctrl+F2` 또는 줄 번호 오른쪽 여백 클릭으로 표시/해제, `F2` / `Shift+F2`로 다음·이전 북마크(끝에서 순환). `검색 → 북마크`에서 찾은 줄 모두 북마크, 북마크한 줄 복사·삭제, 모두 지우기. 북마크는 세션에 저장되어 재실행 후에도 남습니다. |
| 같은 문서 분할 | `보기 → 같은 문서 위아래 분할`. 한 문서를 위아래 두 화면으로 보고 어느 쪽에서든 편집합니다. 클릭한 화면에 명령이 적용됩니다. 미리보기 모드를 켜면 분할이 풀립니다. |
| 함수 목록 | `보기 → 함수 목록`. 오른쪽 패널에 함수·클래스·Markdown 제목 등을 줄 번호와 함께 표시하고 클릭하면 이동합니다. C/C++/C#/Java/JavaScript/TypeScript/PHP/Python/SQL/Go/Rust/Ruby/Perl/VB/Lua/셸/PowerShell/배치/INI를 지원합니다. 줄 단위 규칙으로 찾는 간이 목록이라 문법 분석기만큼 정확하지는 않습니다. 편집 후 잠시 뒤 갱신되며 패널 표시 여부는 세션에 저장됩니다. |
| 일치 개수 | 찾기 창의 `일치 개수` 버튼으로 현재 텍스트/Hex 문서 전체의 총 일치 개수를 표시합니다. 커서·선택 영역과 문서 내용은 유지합니다. |

| 매크로 | Ctrl+Shift+R로 녹화 시작/중지, Ctrl+Shift+P로 실행. 지정 횟수 또는 문서 끝까지 반복, Esc 중지, 이름 저장·관리. |

| 세로 선택 | Alt+드래그 또는 Alt+Shift+방향키. Ctrl+클릭으로 다중 커서를 추가합니다. |
| 최근 파일 | `파일 → 최근 파일`에 직접 열거나 저장·닫은 파일 15개를 최신 순으로 표시합니다. 없는 파일은 목록에서 제거할지 묻습니다. 재실행 후에도 유지됩니다. |
| 탭 관리 | 탭을 드래그해 순서를 바꿉니다. 탭 우클릭·파일 메뉴에서 다른 탭/오른쪽 탭/모든 탭 닫기, 파일 경로 복사를 사용합니다. `Ctrl+Shift+T`는 최근에 닫은 저장 파일 탭을 다시 엽니다(최대 20개). |
| 설정 | `도구 → 설정…`에서 탭 너비(1~16), Tab 키의 탭/공백 입력, 괄호 짝 강조, 자동 들여쓰기를 지정합니다. 모든 텍스트 탭에 즉시 적용되고 세션에 저장됩니다. 기본값은 공백 4칸입니다. |
| 주석 넣기 / 빼기 | `Ctrl+Q`. 언어별 Notepad++ 주석 기호를 사용합니다. 줄 주석이 있는 언어는 선택한 각 줄의 들여쓰기 뒤에 넣거나 빼고 빈 줄은 건너뜁니다. HTML·CSS처럼 블록 주석만 있는 언어는 선택 영역(없으면 현재 줄)을 감싸거나 풉니다. 한 번에 실행 취소되며 매크로에 기록됩니다. |
| 대소문자 변환 | `Ctrl+Shift+U` 대문자, `Ctrl+U` 소문자, `편집 → 대소문자 변환`의 단어 첫 글자 대문자. 다중 선택에도 적용됩니다. |
| 괄호 짝 | 커서 옆 `()[]{}`의 짝을 청록색으로, 짝이 없으면 빨간색으로 표시합니다. `Ctrl+B`로 짝 괄호로 이동합니다. 200 MiB 초과 대용량 모드에서는 끕니다. |

| 열 일괄 편집 | 여러 행을 선택한 후 Alt+C에서 문자열 또는 시작 값·증가 값의 연속 숫자를 넣습니다. |

| 탭 비교 | Ctrl을 누르고 두 탭을 클릭하거나 탭 우클릭으로 선택한 후 Ctrl+Alt+C. 추가·삭제·변경 줄 색상, 동기 스크롤, F7 / Shift+F7 이동을 지원합니다. |

| 탭 저장 상태 | 타자기 본체가 파스텔 민트색이면 수정 없음, 파스텔 빨강이면 미저장 변경입니다. 두 상태 모두 바깥 배경은 투명합니다. 저장하거나 변경을 모두 되돌리면 민트색으로 돌아옵니다. |

| 파스텔 도구 모음 | 상단 버튼은 16px 격자로 다시 그린 아이콘으로 표시하며 화면 배율별 크기를 골라 선명하게 보입니다(`tools/toolbar-icons`). 마우스를 올리면 기능명·단축키가 툴팁에 나옵니다. 눌린 테두리는 현재 보기/모니터링 상태, 파스텔 파랑·빨강 원은 녹화 대기·진행 상태입니다. |

| Markdown·HTML·SVG 미리보기 | 상단의 원문 / 미리보기 / 분할 보기 버튼으로 전환합니다. 저장 전 내용도 400ms 입력 대기 후 자동 반영합니다. |

| 문서 정렬 | HTML/XML/JSON/SQL 문서 또는 선택 영역에서 Ctrl+Alt+F. 언어 메뉴에서 종류를 지정할 수 있습니다. |

| 자동 들여쓰기 | Enter를 누르면 윗줄의 선행 탭·공백을 다음 줄에도 이어 줍니다. 기본으로 켜져 있으며 `편집 → 자동 들여쓰기`에서 전환합니다. 설정은 다시 실행해도 유지됩니다. |

| 일관된 팝업 | 찾기·줄/오프셋 이동·열 편집·매크로·안내/확인 창은 같은 글꼴, 버튼 높이, 간격과 여백을 사용합니다. 내용에 맞춰 창 높이를 정하고 긴 안내는 스크롤로 표시합니다. |

| 코드 접기·구간 표시 | C 계열 중괄호와 HTML/XML 태그 등의 구조를 접습니다. 행번호 옆 +/−로 접기·펼치기, 세로 연결선으로 펼쳐진 구간 범위를 표시합니다. `보기 → 코드 접기`에서 현재 구간·전체·단계별로 조작합니다. |

| 기호 보기 | 보기 메뉴의 공백·탭, 줄바꿈, 제어 문자, 모든 기호 표시. |

| 언어·구문 강조 | Notepad++ 공식 소스의 언어 매핑·기본 스타일·키워드 데이터를 포함합니다. 확장자 자동 감지와 언어 메뉴의 수동 선택을 지원합니다. |

| 인코딩 | Notepad++에서 사용하는 Windows·DOS·ISO·한국어·일본어·중국어 계열과 UTF 계열. '다시 열기'와 '저장 인코딩 변환'을 구분하며 표현 불가능한 문자가 있으면 저장을 중단합니다. |

| 세션 복원 | 탭 순서, 활성 탭, 미저장 내용, 인코딩·언어, 커서·다중 선택, 줄바꿈·배율을 복원합니다. |

| 창 크기 복원 | 종료할 때 일반 창 크기·위치와 최대화 여부를 저장합니다. 최소화한 채 종료하면 최소화하기 전 상태로 다시 표시하며, 모니터가 바뀌면 현재 화면 안으로 보정합니다. |

| 외부 변경 감지 | 창으로 돌아오면 열린 파일의 수정 시각·길이·Windows 파일 ID를 확인하고 다시 불러올지 묻습니다. 미저장 편집 내용이 있으면 경고하며, 거절하면 현재 내용을 유지합니다. |

| 로그 모니터링 | 저장된 텍스트 탭에서 `로그 모니터링`을 켜면 1초마다 추가된 부분만 읽습니다. 읽기 전용이며 찾기·복사·선택을 사용할 수 있습니다. `끝 따라가기`를 끄면 현재 분석 위치를 유지합니다. |



## 자동 들여쓰기



HTML·프로그래밍 언어와 일반 텍스트에서 Enter를 누르면 이전 줄의 탭·공백 들여쓰기를 그대로 이어 줍니다. 예를 들어 선행 탭이 두 개인 줄 끝에서 Enter를 누르면 새 줄에도 탭 두 개가 들어가고 그 뒤에 커서가 놓입니다. 공백 네 칸이나 탭·공백이 섞인 들여쓰기도 원래 문자를 보존합니다. 줄 중간에서는 새 줄로 넘어가는 뒷부분 앞에 같은 들여쓰기를 붙입니다.



`편집 → 자동 들여쓰기`는 기본으로 켜져 있으며 모든 텍스트 탭에 적용됩니다. 켜짐/꺼짐 설정은 세션에 저장됩니다. 붙여넣기·파일 불러오기·로그 수신에는 들여쓰기를 덧붙이지 않으며, Enter와 그에 따른 들여쓰기는 한 번의 실행 취소로 되돌릴 수 있습니다. 매크로의 줄바꿈도 대상 줄의 들여쓰기를 이어 줍니다.



## 코드 접기와 구간 표시



C/C++·C#·JavaScript 등의 `{ }`, HTML/XML의 태그, JSON 등의 계층은 문서 언어의 Scintilla/Lexilla 구조 분석에 따라 접을 수 있습니다. 행번호 오른쪽의 `−`를 누르면 구간이 접히고 `+`를 누르면 펼쳐집니다. 펼쳐져 있을 때는 같은 여백의 세로 연결선이 구간 시작부터 끝까지 이어집니다. 언어는 파일 확장자로 선택되며 새 문서나 다른 확장자는 `언어` 메뉴에서 지정하세요.



`보기 → 코드 접기`에서 현재 커서가 속한 구간, 모든 구간, 1~8단계 구간을 접거나 펼칩니다. 가장 바깥 구간이 1단계입니다. `Ctrl+Alt+B`는 현재 구간 전환, `Alt+0`은 모두 접기, `Alt+Shift+0`은 모두 펼치기입니다. `Alt+1~8`과 `Alt+Shift+1~8`은 해당 단계의 접기·펼치기입니다.



접기는 문서 내용·저장 상태·실행 취소 기록을 바꾸지 않습니다. 접힌 내용도 검색하며, 찾은 항목은 펼쳐서 보여 줍니다. 일반 텍스트·Hex·미리보기 전용 화면과 구문 분석을 끄는 200 MiB 초과 대용량 모드에서는 접기 메뉴를 비활성화합니다. 다시 열기와 언어 변경 시 접힌 구간을 펼칩니다.



## Hex 검색과 일치 개수



Hex 탭의 찾기 창은 기본적으로 `텍스트 UTF-8`입니다. `program` 같은 문자열을 그대로 입력해 `다음 찾기`를 누르세요. UTF-16 LE와 ASCII도 선택할 수 있습니다. 실제 16진수를 검색할 때는 `Hex 바이트`를 선택하고 `70 72 6F 67 72 61 6D`처럼 입력합니다. 잘못된 바이트 입력은 찾기 창 안에 한글로 안내합니다. Hex 검색은 대소문자를 구분하는 바이트 검색이며, 텍스트 전용 정규식·단어 단위 옵션과 지원하지 않는 이전 찾기·모두 바꾸기 버튼은 비활성화합니다.



`일치 개수`는 현재 문서 전체에서 겹치지 않는 일치 항목의 총수를 셉니다. 텍스트에서는 대소문자·단어 단위·정규식 옵션을 적용합니다. Hex에서는 선택한 바이트/문자 인코딩을 적용하고, 아직 저장하지 않은 편집도 포함합니다. 결과 목록이나 별도 결과창을 만들지 않으며, 커서와 선택 영역은 이동하지 않습니다. 큰 파일의 계산은 `중지` 버튼으로 취소할 수 있습니다.



## 외부 변경과 로그 분석



일반 문서는 LHPad 창을 다시 활성화할 때 변경을 확인합니다. `보기 → 외부 파일 변경 확인`으로 직접 확인할 수도 있습니다. 같은 변경에 대해 다시 불러오기를 거절하면 반복해서 묻지 않으며, 이후 다른 변경이 생기면 다시 알립니다. 파일이 삭제되거나 이동되어도 열린 내용은 유지합니다. 다시 불러오기는 새 문서에 읽기를 마친 뒤 현재 탭에 적용하므로 읽기·인코딩 오류가 발생해도 기존 편집 내용이 남습니다. 선택한 인코딩과 언어, 커서·화면 위치를 유지합니다.



로그 파일을 열고 상단 또는 보기 메뉴의 `로그 모니터링`을 켜세요. 편집한 문서는 먼저 저장해야 합니다. 모니터링 중에는 편집·저장을 막고, 검색과 복사는 허용합니다. `끝 따라가기`를 켜면 새 내용이 추가될 때 파일 끝을 표시합니다. 끄면 선택 영역과 화면 위치를 유지하면서 내용을 계속 받습니다. 같은 버튼으로 모니터링을 끄면 일반 편집으로 돌아옵니다. 모니터링은 다시 실행할 때 자동으로 켜지지 않습니다.



증가한 내용은 한 번에 최대 256 KiB씩 읽고, 여러 번에 나뉘어 기록된 한글·다중 바이트 문자도 이어서 해석합니다. 로그가 비워지거나 새 파일로 교체되면 내용을 새 로그로 바꿉니다. 파일이 잠시 사라지거나 잠기면 기존 화면을 유지하고 다음 주기에 재시도합니다. 작성 프로그램이 사용 중인 파일도 공유 읽기가 허용되어 있으면 열 수 있습니다. 로그 인코딩이 바뀌면 모니터링을 중지하고 맞는 인코딩으로 다시 열어 주세요.



로그 모니터링은 텍스트 파일에서 지원합니다. Hex 원본은 편집 기준 바이트를 유지하기 위해 직접 쓰기 잠금을 유지하며, 다른 프로그램의 파일 교체·삭제는 감지합니다. 일반 변경 감지는 파일 메타데이터를 사용하고, 로그 교체 감지는 파일 ID와 앞부분·읽은 경계 바이트를 추가로 확인합니다.

## 매크로



1. 편집 가능한 텍스트 탭에서 **매크로 → 녹화 시작 / 중지** 또는 `Ctrl+Shift+R`을 누릅니다.

2. 키보드 편집·커서 이동, 찾기·바꾸기 등의 작업을 수행합니다.

3. `Ctrl+Shift+R`을 다시 눌러 녹화를 마칩니다.

4. 실행할 위치에 커서를 두고 `Ctrl+Shift+P`로 한 번 실행하거나 **여러 번 실행**에서 횟수 또는 **문서 끝까지**를 선택합니다.



- 문서 끝까지 반복할 때는 보통 **Home → 접두사 입력 → 아래 방향키**처럼 다음 줄로 이동하는 동작을 포함합니다. 현재 위치부터 마지막 줄까지 처리하고, 커서 진행·문서 축소가 없으면 자동 중지합니다. 마지막 검색 결과가 없을 때도 중지하며 이 모드에서는 문서 처음으로 검색을 순환하지 않습니다.

- 지정 횟수는 1~1,000,000회입니다. 실행 중 `Esc` 또는 중지 버튼으로 멈출 수 있고, 완료·중지된 실행의 편집 내용은 `Ctrl+Z` 한 번으로 되돌립니다.

- **현재 녹화 저장**으로 이름을 붙여 보관합니다. 현재 녹화와 저장된 매크로는 `%LOCALAPPDATA%\LitePad\macros.json`에 남아 재실행 후에도 사용할 수 있습니다. 매크로 관리에서 이름 변경·삭제가 가능합니다.

- 한글·UTF-8 입력, 삭제, 키보드 커서·선택 이동, 복사·붙여넣기, 검색·바꾸기와 정규식, 줄바꿈 변환, 문서 정렬·줄 정렬, 열 편집을 지원합니다. 붙여넣기는 실행 시점의 클립보드를 사용합니다.

- 매크로는 현재 텍스트 탭에 실행합니다. 마우스 좌표, 파일 열기·저장·닫기, Hex 편집, 웹 미리보기 조작은 녹화 대상이 아닙니다. 여러 탭 전체 바꾸기는 녹화 중 해제해야 합니다. Notepad++의 shortcuts.xml 가져오기는 지원하지 않습니다.

- 녹화는 최대 100,000단계, 개별 문자열은 4 MiB까지 지원합니다.



## Markdown·HTML·SVG 미리보기



- `.md`, `.markdown`, `.mdown`, `.mkd`, `.html`, `.htm`, `.xhtml`, `.svg`를 지원합니다. 새 문서는 언어 메뉴에서 Markdown 또는 HTML을 선택하세요.

- 기본은 원문 편집입니다. **미리보기**는 문서 전체를, **분할 보기**는 원문과 렌더링 결과를 나란히 표시합니다.

- Markdown은 제목, 강조, 목록·체크박스, 표, 인용, 링크, 코드 블록, 이미지, 각주를 지원합니다. Mermaid 실행, 수식 조판, 코드 블록 색상 강조는 포함하지 않습니다.

- HTML은 작성한 문서와 CSS를 브라우저에서 렌더링합니다. 같은 폴더와 하위 폴더의 이미지·CSS·폰트를 상대 경로로 불러옵니다. 저장되지 않은 새 문서는 상대 경로 기준 폴더가 없습니다.

- 문서 외부의 CSS·이미지 파일을 수정한 경우 **새로고침/F5**를 누르세요. 원문의 변경은 자동 반영됩니다.

- HTML JavaScript는 기본 꺼짐이며 미리보기 상단의 **HTML 스크립트**를 눌러 이 탭에서 실행할 수 있습니다. 이 실행 설정은 재시작 때 초기화합니다. 외부 리소스 URL은 브라우저에서 불러오므로 네트워크가 필요할 수 있습니다.

- 로컬 문서 링크는 LHPad 탭으로, 사용자가 클릭한 웹 링크는 기본 브라우저로 엽니다.

- 미리보기는 **4 MiB 이하** 문서를 지원합니다. 더 큰 문서의 원문 편집·저장에는 이 제한을 적용하지 않습니다.

- 탭의 원문/미리보기/분할 모드는 종료 후 복원합니다. 미리보기가 원본 파일을 자동 저장하지 않습니다.



## 세션·파일 보존



- 기본 복원 폴더: `%LOCALAPPDATA%\LitePad`. 도구 메뉴에서 열 수 있습니다.

- 3초마다 변경 문서의 스냅샷을 별도로 저장하고 종료 때 다시 저장합니다. 큰 문서의 백업에는 시간이 추가로 걸립니다. 강제 종료 시 마지막으로 완료된 백업까지 복원됩니다.

- 정상 종료는 미저장 문서를 그대로 보관합니다. **탭을 개별적으로 닫을 때 '아니요'를 선택하면 해당 탭의 변경 내용을 버립니다.**

- 저장은 같은 디렉터리의 임시 파일을 완성한 다음 원자적으로 교체합니다. 디스크 파일의 수정 시간/길이가 달라졌으면 덮어쓰기 전에 확인합니다.

- 현재/직전 두 세션 매니페스트를 유지합니다. 읽지 못한 탭의 복원 항목도 버리지 않고 다음 실행을 위해 보존합니다.

- 같은 프로필을 동시에 여는 두 번째 프로세스는 복원 데이터 충돌을 막기 위해 실행하지 않습니다. 별도 프로필은 `LHPad.exe --profile "C:\path\profile"`로 지정할 수 있습니다.



## 현재 범위와 한계



- 0.3 초기 구현입니다. Notepad++/HxD 전체 기능이나 완전한 동작·모양의 동일성을 보장하지 않습니다. 플러그인, UDL 사용자 언어 편집기, 디스크/RAM 직접 편집은 포함하지 않습니다.

- 텍스트 파일은 편집을 위해 전체 내용을 **네이티브 메모리**에 올립니다. 사용 메모리는 파일 크기·줄 수·되돌리기 이력에 비례합니다. 디스크 기반 무제한 크기 텍스트 편집기는 아닙니다. 검증 크기는 텍스트 256 MiB, 바이너리 3 GiB입니다.

- 정렬은 선택 영역/문서 32 MiB 이하, 비교는 각 문서 32 MiB 이하·두 문서 합계 400,000줄 이하입니다. 큰 파일은 계속 열고 편집·저장할 수 있습니다.

- 비교는 줄 내용을 정확히 비교하며, 공백·줄바꿈 차이 무시 옵션은 없습니다. 비교 창은 비교 시점의 읽기 전용 스냅샷입니다. 거대한 반복 구간에서는 최소 편집 경로 대신 변경 블록으로 표시할 수 있습니다.

- SQL 정렬은 토큰 순서를 보존하는 어휘 기반 정렬이며 SQL dialect 전체를 파싱하는 검증기는 아닙니다. HTML은 텍스트와 script/style/pre/textarea를 유지하며 블록 경계를 정렬합니다. XML/JSON 정렬은 올바른 문법이 필요합니다.

- 바이너리의 문자 영역은 Windows-1252입니다. Hex 뒤로 찾기와 모두 바꾸기는 아직 없으며 현재 항목 바꾸기는 같은 길이로 덮어씁니다. 삽입·삭제·붙여넣기로 파일 길이를 바꿀 수 있습니다.

- 레거시 인코딩 자동 감지는 휴리스틱입니다. 애매한 문서는 인코딩 메뉴에서 지정해 다시 여세요. Notepad++의 모든 언어별 세부 lexer 속성·내장 웹 언어 조합은 아직 완전히 맞추지 않았습니다.



## 빌드·검증



```powershell

./build.ps1

./build.ps1 -Test

./build.ps1 -RebuildNative -Test

./build.ps1 -OutputDirectory artifacts/native-1.4.0

# 보존된 C# 0.5.2 버전을 별도로 빌드할 때만:

./build.ps1 -CSharp -OutputDirectory artifacts/legacy-csharp

```



버전 번호는 `cpp/version.h`의 `LHPAD_VERSION_MAJOR/MINOR/PATCH` 한 곳에서만 바꿉니다. 실행 파일 리소스, 정보 창, MSIX 패키지 버전, 탐색기 메뉴 패키지 검사, CMake, 배포 스크립트의 기본 폴더·ZIP 이름이 이 값을 따릅니다. 릴리스 노트 `docs/RELEASE-x.y.z.md`는 직접 작성합니다.



현재 기본 빌드는 **Visual Studio C++ 데스크톱 도구 + Windows SDK**만 사용하며 .NET SDK나 NuGet 복원이 필요하지 않습니다. `cpp/`에 C++20 소스, JSON·XML·Markdown 라이브러리 소스와 WebView2 네이티브 SDK를 포함했습니다. C/C++ 런타임은 `/MT`로 정적 연결합니다. `vendor/notepad-plus-plus-src.zip`에 Scintilla/Lexilla/Boost의 기준 소스를 포함했으며 `cpp/patch-scintilla.ps1`이 파일 드롭 처리를 추가합니다. 네이티브 엔진을 다시 빌드하지 않으면 `native/`의 사전 빌드된 DLL을 사용합니다. 파스텔 도구 모음 PNG는 기존 벡터 아이콘을 미리 내보낸 자산이므로 빌드에 .NET이 필요하지 않습니다. 보존된 C# 버전의 `-CSharp` 빌드에만 .NET 10 SDK와 기존 NuGet 패키지가 필요합니다.



PowerShell 스크립트 대신 CMake도 사용할 수 있습니다. Visual Studio에서 `cpp/CMakeLists.txt`를 열거나 C++ 개발자 명령 프롬프트에서 `cmake -S cpp -B artifacts/cmake -A x64`, `cmake --build artifacts/cmake --config Release`를 실행합니다. 이 경로 역시 .NET SDK와 NuGet을 사용하지 않습니다.



테스트는 실제 Scintilla·Hex 엔진과 창 닫기/재실행 복원을 검사합니다. 테스트 결과·미리보기는 실행 폴더의 `test-results/`에 생성됩니다. 임시 256 MiB 텍스트와 3 GiB 바이너리 파일은 테스트 후 삭제하며 사용자 파일을 건드리지 않습니다.

## 메인 아이콘



현재 메인 아이콘은 내장 ImageGen으로 만든 파스텔 민트·하늘색 빈티지 타자기입니다. 아이보리 종이와 건반, 짙은 회청색 롤러와 얇은 윤곽선을 사용하며, 바깥 바탕이나 사각형 테두리 없이 실제 알파 투명 배경으로 표시합니다. `data/LHPad.ico`는 16/20/24/32/40/48/64/128/256픽셀 프레임을 포함하며 실행 파일과 창에 적용됩니다. 원본 PNG는 `data/LHPad-icon.png`, ICO 재생성 스크립트는 `tools/build-icon.ps1`입니다. 문서 탭도 같은 타자기를 사용하며, 본체 색상이 민트색이면 저장 상태, 파스텔 빨강이면 미저장 상태입니다. 배경은 두 상태 모두 투명합니다.



`도구 → LHPad 정보`에는 메인 아이콘을 128×128 논리 픽셀로 크게 표시합니다. 256px ICO 프레임을 사용하며 화면 배율에 맞춰 선명하게 축소합니다. 버전·구성 요소·라이선스·주요 단축키는 아이콘 아래에 배치합니다.



0.4.3에서는 전체 둥근 사각형, 종이와 접힌 모서리, 연필 각각에 얇은 검은 테두리를 추가했습니다. 저장 탭은 배경이 투명하고 미저장 탭은 파스텔 빨강입니다. 상단 버튼은 `매크로 반복 실행`으로 전체 이름을 표시하며 글자 폭에 맞춰 너비를 잡습니다. 이미지의 최종 프롬프트와 제작 방식은 `docs/ICON.md`에 기록했습니다.



0.4.4에서는 탭 아이콘을 실제 표시 크기로 한 번만 그리며, 외곽선을 픽셀 격자에 맞춰 네 방향 모두 표시합니다. 테두리 바깥에는 투명한 여백을 두어 오른쪽·아래가 잘려 보이는 문제를 수정했습니다.



0.4.5에서는 상단 기능을 파스텔톤 아이콘으로 표시하고 버튼 글자는 툴팁과 접근성 이름으로 유지합니다. 도구 모음의 도움말 아이콘에서도 세로 선택·다중 커서·탭 비교 단축키를 확인할 수 있습니다.



0.4.6에서는 메인과 문서 탭 아이콘을 투명 배경의 빈티지 타자기로 변경했습니다. 탭은 저장 상태에서 파스텔 민트색, 미저장 상태에서 파스텔 빨강 본체를 표시하며 종이·건반·배경은 동일하게 유지합니다. 예전 탭의 사각형 프레임과 상태별 배경색을 제거하고 실제 표시 크기별 캐시와 투명 여백을 유지했습니다.
